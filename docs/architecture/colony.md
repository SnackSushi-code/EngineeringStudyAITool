# Colony Architecture Baseline

The Colony is a visual multi-agent simulation and orchestration surface.

## Roles

- Command Ann-E
- Engineer Ann-E
- Warrior/Security Ann-E
- Researcher Ann-E
- Study Ann-E
- Builder/Worker Ann-E

## Systems

- agent registry
- task scheduler
- role permissions
- event bus
- pathfinding
- resource model
- job queues
- simulation clock
- replay
- fault injection
- telemetry

The Colony can represent real Ann-E backend jobs, but a visual agent is never granted additional real-world privileges merely because it exists in the simulation.
