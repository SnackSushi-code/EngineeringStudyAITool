# External Integration Policy

For every external repository or software integration:

1. Identify official source.
2. Record license.
3. Record exact version/revision.
4. Inspect maintenance status.
5. Inspect dependency graph.
6. Run security/static analysis where practical.
7. Isolate through an adapter.
8. Define required permissions.
9. Add contract/integration tests.
10. Define removal/migration path.

Initial requested integrations include CAI and Refact. Both are treated as external components, not trusted Ann-E core code.
