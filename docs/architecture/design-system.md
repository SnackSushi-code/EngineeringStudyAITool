# Ann-E Design System Baseline

## Identity

Ann-E's supplied reference artwork defines the product's original visual identity:
- rounded white hovering robot
- black visor
- cyan/blue luminous eyes
- soft cyan hover effect
- friendly technical personality

## Application

- dark navy/near-black surfaces
- cyan/blue technical accents
- restrained glass/depth effects
- strong typography hierarchy
- consistent spacing/radius tokens
- accessible contrast

## Widget states

IDLE, LISTENING, THINKING, SPEAKING, WORKING, SUCCESS, WARNING, ERROR, SLEEPING, OFFLINE.

The widget must remain lightweight and GPU accelerated where available.
